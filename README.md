## 🔍 About

This is an unofficial port of the **Exposure** mod to Minecraft **1.21.11 (Fabric)**. The original mod supports versions up to 1.21.1 — this fork bridges the gap for newer versions.

> **Exposure** is a mod that adds film cameras to Minecraft. Take photos, develop film, create albums. Focused on process and aesthetics.

---

## ✨ What's changed in this fork

- ✅ Full port to **Fabric 1.21.11** (API, mappings, dependencies)
- ✅ Compatibility with the latest **Fabric API**
- ✅ Fixes for the new rendering API (`Screen`, `GuiGraphics`)
- ✅ Updated `gradle.properties` and build dependencies
- 🔧 In progress: full mechanics testing

---

## 🎮 Features

- **Film cameras** — capture the world in first or third person
- **Film development** — develop film in-game, not just instant photos
- **Photo albums** — collect and share your shots
- **Filters & effects** — control exposure, light and composition
- **Resource Pack / Data Pack API** — customize for your adventure

---

## 📦 Installation

1. Install [Fabric Loader](https://fabricmc.net/use/) for **1.21.11**
2. Download [Fabric API](https://modrinth.com/mod/fabric-api) for 1.21.11
3. Download the `.jar` from [Releases](https://github.com/BelzeBool/Exposure/releases)
4. Drop it into your `mods/` folder

> ⚠️ This is a work-in-progress port. Bugs are possible. Issues are welcome.

---

## 🔨 Building from source

```bash
git clone https://github.com/BelzeBool/Exposure.git
cd Exposure
git checkout 1.21.11
./gradlew build
```

The artifact will appear in `fabric/build/libs/`.

## 🔍 О проекте
